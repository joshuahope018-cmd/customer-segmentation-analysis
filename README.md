# customer-segmentation-analysis
The project uses K-means clustering,an unsupervised machine learning algorithm to segment mall customers into different groups based on their annual income and spending score.
The elbow method is used to determine the optimal number of clusters,followed by visualization and interpretation of each customer segment
## Interpretation of Clusters
Cluster 0:High income,high spending custormers

Cluster 1:Low income,low spending customers

Cluster 2:High income,low spending customers

Cluster 3:Low income,high spending customers

Cluster 4:Medium income,medium spending customers
## Marketing strategies
### High Income-High Spending
They are rewarded with loyalty programs and exclusive offers.
### High Income-Low Spending
They are encouraged to spend using personalized discounts and premium promotions.
### Low Income-High Spending
Are offerd with affordable promotions,coupons and seasonal discounts.
